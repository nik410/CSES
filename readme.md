<b>For java</b>

Compiling java file :
```bash
javac fileName.java
```

Creates .class files

To run
```bash
java fileName
```

<b>For c ++</b>
```bash
g ++ fileName.cpp
 ```
The above command creates an executable file named a.exe 

Run the executable by using the below command
```bash
.\a.exe
 ```
